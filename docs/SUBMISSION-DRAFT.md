## What the rules require

1. A project that meaningfully uses the PayPal developer platform (sandbox)
   and an AI tool, model, or platform of your choice. The PayPal Agent
   Toolkit is not required.
2. A text description of features and functionality.
3. A functional demo: complete setup instructions in the repo, or a hosted
   URL. A mockup is not enough.
4. Tools used, and how they were used.
5. A public GitHub, GitLab, or Bitbucket repo with all source, a visible
   open-source license file, and run instructions.
6. A YouTube demo video, public, under 3 minutes, showing the project working,
   with no unlicensed music or third-party trademarks.

Judging (equally weighted): Technological Implementation, Design, Potential
Impact, Innovation/Idea, and Presentation.

Prizes include overall cash prizes and sponsor prizes. Best Use of Render is
$1,000 / $750 / $500 in Render credits. A project can win at most one Grand
Prize and one Sponsor Prize, or one Honorable Mention and one Sponsor Prize.

Winners are announced on or around Monday 21 December 2026, 2:00 pm Pacific.

## Suggested tools field

Rule-based invoice parser (no API key) for reading invoices and chat messages,
with an optional OpenAI-compatible model if a key is set. PayPal Orders v2
sandbox API for the checkout link. open.er-api.com and Frankfurter for
mid-market FX. FastAPI and a static front end, ready to host on Render.

## Suggested short description

Kudi helps a Nigerian freelancer turn a messy invoice or
chat message into a PayPal sandbox payment link, then explains official PayPal
fees and a mid-market Naira estimate in plain English. PayPal does not settle
in NGN, and the app says so clearly.
